Project Overview & Structure

This project is a modern, responsive personal portfolio website built with Angular 19. It features a clean, glassmorphism-inspired UI with a dedicated section for daily news highlights.

🏗️ How it was built

  • Framework: Angular 19 (Standalone Components)
  • Language: TypeScript
  • Styling: Vanilla CSS with modern features like CSS Variables, Grid, and Flexbox.
  • Deployment: Configured for GitHub Pages via angular-cli-ghpages.

📂 Project Structure

Root Directory

  • angular.json: Configuration for the Angular CLI (build, test, and serve settings).
  • package.json: Project dependencies and scripts (e.g., npm start, npm run build).
  • src/: The main source code folder.
    • styles.css: Global styles and design tokens (colors, variables).
    • app/: Contains all application logic and components.

🧩 Component Breakdown

Core Layout

  • AppComponent: The root container that holds the Header, Footer, and the main Content area (driven by the router).
  • HeaderComponent: Sticky navigation bar with "Home" and "Daily New Bytes" links.
  • FooterComponent: Social connection links (LinkedIn, Facebook).

Home Page Components

The Home page uses a responsive grid layout to organize these cards:

  • HomeComponent: Orchestrates the grid layout for the tiles.
  • ProfileTileComponent:
    • Displays your name, role, and profile photo.
    • Includes a fallback mechanism if the profile photo fails to load.
    • Quick action buttons for LinkedIn and Resume download.
  • AboutTileComponent:
    • A dedicated card for your biography and current interests (Tennis, Coding, etc.).

Features

  • DailyBytesComponent:
    • A unique "News Briefcase" feature.
    • Uses a terminal-style animation to simulate an agent gathering news.
    • Fetches live data from The Guardian API (if a key is provided).
  • NewsService: Handles the logic for API communication and local storage for the API key.

🚀 Key Features

  1. Glassmorphism UI: Uses translucent backgrounds and blurs for a premium look.
  2. Responsive Grid: Automatically switches from 1 to 2 columns based on screen size.
  3. Animated Transitions: Smooth fade-in and hover effects on cards.
  4. Standalone Architecture: Modern Angular pattern that eliminates the need for NgModules.
